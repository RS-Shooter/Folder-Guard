So, this is my first project, so please don’t judge it too harshly. It’s a file blocker that works by keeping files or folders open—in a way that’s invisible to the average user—which prevents them from being accessed. 
The interface is quite straightforward, but I recommend using the "lock folder" option rather than "lock file," as the latter doesn’t work very well, and I currently lack the skills to refine it further.
